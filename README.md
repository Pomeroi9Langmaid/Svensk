# Svenska Nära

A free Swedish news and vocabulary-learning microsite for Andrew.

## Features
- Free SVT national and regional RSS news
- Göteborg and Västsverige prioritisation
- Highlight a difficult word to save it locally
- Personal vocabulary bank stored in the browser
- Practice stories using five starter expressions
- Quick recall test

## Starter expressions
- ställa in = cancel
- ta reda på = find out
- hålla med = agree
- på grund av = because of
- det visar sig att = it turns out that
